# PV 渲染器 · 初版

本地运行，1920×1080 固定逻辑画布。两个模式使用相同谱面和怪物分配，分别表现全部击打和全部 Miss。动画导入器作为素材窗口嵌入，继续复用 software/animation-importer 源码。

## 启动与使用

双击 start.cmd，再在浏览器打开 http://127.0.0.1:5175/，保持终端运行。也可在本目录运行 npm run dev。开发和构建脚本固定复用相邻 chart-editor 的依赖；首次使用需先在 software/chart-editor 中运行 npm.cmd install --cache .npm-cache，或启动一次该目录的 start.cmd。

1. 导入制谱器 JSON 和本地音乐。支持当前浏览器可解码的 FLAC、WAV、MP3 等；音乐信息与谱面不同会提示确认。无效导入保留原内容。
2. 点击“素材”。可以点击“载入项目素材”加载工作区现有等距白边 PNG，也可以分别导入六个槽位。默认项目预设使用待机首帧主体中心作为四组人物统一锚点，是可调的起始值，不代表已人工校准。
3. 在素材窗口进行第一帧锚点、整组缩放、旋转和裁剪；点击“应用”更新主预览，然后关闭窗口。未应用的修改关闭时可以放弃。每组动作第一帧锚点沿用至后续帧。
4. 设置片段开始和结束、播放模式及动作参数。时间滑块定位后暂停，可从该处继续。Space 播放/暂停。没有循环预览。
5. “保存谱面”保存 seed；“保存配置”保存渲染参数、怪物启用列表及素材矫正。配置只包含已应用的素材修改；素材窗口中的“保存配置”另存素材专用 JSON，需在该窗口打开。JSON 不包含图片或音乐。重新打开时分别关联谱面、音乐、素材；在素材窗口按原文件名关联可保留矫正，避免使用会重置矫正的“载入项目素材”按钮。
6. 使用系统录屏软件录制。“录屏模式”进入全屏、隐藏调试叠层和鼠标，并从片段开始处倒计时播放。Esc 退出并暂停。当前不生成 MP4/WebM 文件。

项目预设从根目录 src/EquidistantWhiteEdgeStopMotionMovie/ 读取 Idle、Upper、Lower、Stright、Hitfx、Monsters 子目录。根目录 src/ 已被 Git 忽略，克隆仓库后需自行准备资源，也可在素材窗口手动导入 PNG。怪物数量由素材列表决定。

## 时间与动画规则

命中秒数 = offsetSeconds + tick × 60 / (BPM × 480)。BPM 按四分音符计算；飞行提前拍数也按四分音符计。负的攻击偏移表示提前播放攻击动画；正值表示延后。偏移不改变怪物命中或特效出现时间。

人物直接追踪谱面高度，固定时长 easeOutCubic。密集音符截断旧移动，从当前高度重新缓动；攻击从新动作第一帧开始，始终按素材帧率播放，不加速。人物锚点不按武器命中偏移反推。统一 X/Y 偏移只用于特效定位与调试参考，单位为 1080p 逻辑像素。特效位置基于人物横坐标和音符目标高度，再加该偏移；人物尚未到位时，特效不会随当前人物高度移动。

全部 Miss 时人物在高度 0.5 附近待机浮动，怪物过打击线后继续运动，直到完整离开画面左侧。全部击打暂不支持同刻多音符，会明确提示；Miss 支持。同刻检测只针对当前片段结束前的事件。音乐范围外的音符需要先在制谱器修正。

所有画面状态由 Web Audio 时钟计算，暂停、重播与跳转不依赖之前是否触发事件。画面位移按浏览器刷新率平滑计算，人物与特效按素材窗口帧率（默认 8fps）切换。

“从头播放”和“录屏模式”的预演长度取倒计时、怪物飞行时间、移动提前量和攻击提前时间中的最大值，让片段开头也有入场。普通播放和继续不额外预演。音乐从指定片段时间开始。收尾至少保留设定时长，必要时延长到最后动作、特效或漏过怪物结束，收尾期间没有额外音频。

Seed 写入谱面 meta.seed，旧谱面缺失时默认 1。怪物由 seed + 稳定音符 ID 分配；复现还需要相同的素材配置和启用列表。重新随机只改 seed，不改变音符。

## 工程与验证

- src/engine.js：确定性移动、动作选择、怪物轨迹、配置校验。
- src/clock.js：音频时钟、预演与收尾。
- src/main.js：界面、Canvas、资源和文件操作。
- editor.html：同源素材窗口。复用原导入器，不维护第二份矫正实现。
- npm test：引擎与 seed 兼容测试。
- node tests/browser.mjs：本地 Chrome/Playwright 验证，需要工作区素材及音乐。RENDERER_URL 可指定生产预览地址。
- npm run build：同时生成主页面、素材窗口和当前项目 PNG。

浏览器验证包括真实 PNG/FLAC 导入、嵌入素材应用、两种模式、暂停/继续、跳转画面一致性、seed 导出、无效配置保护、同刻规则、素材重关联、全屏倒计时及播放收尾。浏览器测试不能证明外部录屏软件的实际录制质量。
