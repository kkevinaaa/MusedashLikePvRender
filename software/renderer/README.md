# PV 渲染器

## 启动

在本目录执行 npm install（首次安装），然后双击 start.cmd 或运行 npm run dev，打开 http://127.0.0.1:5175/。素材窗口复用相邻 animation-importer；谱面格式复用 chart-editor。

导入谱面和音乐，打开“素材”导入自己的 PNG 素材，校准后点击“应用”。素材窗口帧率控制人物和特效换帧，例如 12fps。素材组缩放用于组间校正，主页面三组全局缩放用于构图。

## 模式与素材

全部 Miss 使用独立的单张人物立绘，只做正弦上下浮动，沿用待机浮动幅度、周期、人物全局缩放及入退场。素材窗口仅显示人物立绘和怪物，不需要四组动作或特效；网页不内置项目图片，人物立绘需手动导入。切回全部击打保留原动作及校正。独立导入器也支持模式切换；嵌入时由渲染器统一控制模式。素材配置 v2 保存七个独立槽位，兼容读取 v1；旧配置缺少立绘时须导入一次。

全部击打与全部 Miss 分别保存整套渲染参数，包括人物缩放与位置、浮动幅度与周期、活动区域、入退场、怪物、画幅、导出设置和片段范围。切换时自动记住当前参数并恢复另一套，工程 JSON 的 modeSettings 保存两套参数。首次切换时以当前参数作为另一套的初始值；旧工程只有一套时复制为两套，再独立调整。谱面、seed、音乐和素材仍共用。

## 播放和构图

- 全部击打：人物追踪谱面高度，上打、下劈或平砍。密集音符截断旧动作，不加速。
- 全部 Miss：单张立绘在活动区域中心正弦浮动；怪物越过打击线，完整离开左边界后消失。
- 人物、怪物、特效各有显示复选框；只控制绘制，不改变其他对象的运动或事件。为保持动画时间一致，隐藏对象仍需相应素材。
- 活动区域高度、中心以视频画面高度为百分比，不包含浏览器工具栏或黑边。图片越界由使用者手动检查。
- 分辨率优先可独立设置宽高；锁定纵横比支持预设和自定义比例，改一边自动计算另一边。尺寸为 64–4096 像素，MP4 宽高需为偶数。
- 人物、怪物、特效和命中偏移以画面高度为基准缩放，横向位置按画面宽度百分比。画幅变化不会拉伸图片。
- 命中偏移仅乘人物全局倍率，不乘动作组校正倍率。

入场使用 easeOutCubic，先快后慢；退场使用 easeInCubic，先慢后快。入场完成时间为所选片段首音符时刻减去入场提前量，再向前减去入场时长得到开始时间。没有倒计时或额外等待，入场早于音乐片段起点的部分为无声预演。可选退场与怪物离屏会自动延长收尾；空片段不执行入退场。

怪物锚点速度 = 画面右边界到打击线的距离 / 飞行时间，大小不参与速度公式。图片大小只影响进入可见范围和完全离屏的判断。上下飘移有独立开关、幅度和周期，每个音符由 seed + ID 获得固定相位；击打模式在最后 min(0.5 秒, 飞行时间/4) 内平滑收至零，Miss 模式保持飘移。

## 特效

打击特效可开启线性淡出，设置淡出时长和相对每次特效播放起点的延后时间。淡出结束后隐藏；“播完后停留末帧”默认开启：素材先播完时保持最后一帧至淡出结束；关闭则在素材播完时消失，即使淡出尚未完成。关闭淡出时保持原有播放时长。预览、MP4、PNG 共用透明度计算，全局抽帧时透明度也按抽帧率更新；退场及导出收尾会等待特效结束。参数随渲染配置保存。

打击特效的“随机旋转”默认关闭。开启后，每次特效绕素材锚点额外旋转 0～360°，整段动画保持固定角度；角度由谱面 seed 和音符 ID 决定，重播、跳转及两种导出模式保持一致，并叠加素材窗口的校正角度。

## 两种输出模式

正常：人物、特效按素材帧率换图；位移、飘移和入退场连续计算。MP4 和 PNG 可按输出帧率独立采样。

全局抽帧：使用独立的“全局抽帧帧率”（1～120fps，默认 12），所有对象按同一个时间网格更新，包括飞行和飘移。动作与特效仍按素材帧率计算动画进度，不改变动画时长；抽帧较低时可能跳过部分素材帧。攻击起始对齐至下一个抽帧网格点，谱面数据不修改。预览、MP4 和 PNG 均使用该抽帧帧率，不再单独设置视频帧率或要求整数倍。正常模式的输出帧率独立保留。旧配置缺少此参数时沿用其素材帧率。

点击“导出”，按保存方式选择：

- MP4 视频：离线 H.264 视频 + AAC 音频。包含实际音乐片段以及预演、收尾静音。编码慢不会漏帧。需要当前浏览器支持该分辨率的 H.264/AAC 编码，不支持时会明确报错，不会静默导出无声视频。已验证当前本机 Chrome。
- PNG 序列 ZIP：约 96 MiB 分卷，保存完整编号的 PNG 和 timeline.json。大导出可能需要浏览器允许多文件下载。
- PNG 文件夹：选择目录后新建独立子目录，逐帧写入；需浏览器支持本地目录写入。取消时已经写出的图片保留，timeline.json 标记未完成。

所有输出都隐藏调试信息。PNG 不含音频，timeline.json 记录帧率、尺寸、首帧音乐时间、片段音乐起止，以及音乐应放在输出时间线的哪个位置。MP4 内已合入音频。导出可取消；MP4 完成前取消不保存残缺文件。当前 MP4 在内存中封装，超长、高码率片段可优先使用 PNG 文件夹。

## 保存与复现

“保存谱面”保存 meta.seed；旧谱面默认 seed=1，制谱器往返不会丢失。“保存工程”将渲染设置、全部动画导入器配置与原始 PNG、当前谱面（含 seed）和原始音乐文件一并写入 renderer.json（version 2）。打开工程即可恢复播放和导出，不依赖原文件路径，音乐不重新编码。尚未导入的项目保存为 null；已有旧版配置仍可读取，缺少内容需补齐后保存新版。保存时会应用素材窗口当前修改。重新关联原素材文件夹保留矫正。

工程文件使用 Base64 存放二进制素材，比原文件总量约大三分之一，读取和保存时需相应内存。网页不打包任何用户图片，所有素材来自用户导入或工程文件。

工程结构为 version: 2、settings、modeSettings、assets、chart、music。settings 表示当前模式，modeSettings 保存 hit/miss 两套参数；素材校正共用，人物动作和 Miss 立绘分别占用独立槽位。

固定 BPM、480 PPQ；音符秒数 = offsetSeconds + tick × 60 / (BPM × 480)。全部击打不接受同刻多音符，Miss 允许；超出音乐时间范围的音符需在制谱器修正。

## 实现与验证

engine.js 为确定性状态计算，clock.js 为音频时钟，mp4.js 负责离线视频音频编码，zip.js 写入 PNG 分卷。MP4 使用本地浏览器编码及 [Mediabunny](https://mediabunny.dev/guide/writing-media-files) 封装，不上传素材。

npm run build 构建主页面和素材窗口；npm test 验证引擎。node tests/browser.mjs 使用实际 PNG/FLAC 检查交互、PNG ZIP，以及两种 MP4 的轨道、帧率、时长和实际解码。测试使用 Chrome 与 Codex 随附 Playwright。

专门回归脚本：node tests/assets-persistence.mjs（素材配置）、node tests/miss-portrait.mjs（Miss 立绘）、node tests/project-roundtrip.mjs（完整工程和导出）、node tests/mode-settings.mjs（两套参数和旧工程迁移）。测试需本地服务及 src/ 测试素材；fixtures.mjs 只负责测试上传，不会被打包。
