# Contour 制谱器 · 0.1

本地桌面浏览器制谱网页。横轴时间、纵轴高度，仅生成谱面；不含 PV 渲染、人物动画或素材管理。

## 启动

需要 Node.js 20.19+ 或 22.12+。在此目录运行：

```powershell
npm.cmd install --cache .npm-cache
npm.cmd run dev
```

在浏览器打开终端显示的本地地址（通常为 http://127.0.0.1:5173）。也可双击 `start.cmd`，缺少依赖时会自动安装，随后打开网页；使用期间保持终端运行。优先使用桌面 Chrome / Edge；建议窗口宽度至少 1100px。文件只在本机解析，不上传。

```powershell
npm.cmd test
npm.cmd run build
npm.cmd run preview
```

## 使用

1. 导入 FLAC、WAV、MP3 等浏览器可解码的音乐，等待波形生成。解码失败会保留原项目。
2. 设置曲名、固定 BPM、固定拍号与 offset。输入后按 Enter 或移出输入框提交。BPM 以四分音符计；正 offset 表示第 1 小节第 1 拍晚于音乐开头。
3. 点击标尺定位。移动鼠标到下方制谱区域，按 Q 放音符。悬停音符后右键或 Delete 删除。音符支持框选批量删除，不支持移动、复制、撤销或重做，放错请删除后重放。
4. 用滑块选择每拍 2/3/4/6/8 等分；“每拍”按拍号分母定义，例如 6/8 中一拍是八分音符。T 切换时间吸附；V 联动切换高度辅助线的显示及吸附。所有网格更改只影响之后放置的音符。
5. Space 播放/暂停。播放中不能放置或删除音符。滚轮定位时自动暂停；O/P 改变步长（四分音符单位）。画布下方长滑块只平移视图，不改变播放位置。
6. 循环 A/B 可输入秒数，或先定位再点击“设 A / 设 B”。满足 `0 ≤ A < B ≤ 音乐时长` 时可以开启循环，播放从范围内开始，使用 Web Audio 原生循环。修改范围会暂停。
7. Ctrl+S 或“导出 JSON”下载谱面。谱面不包含音乐；重新打开后需要重新关联音乐。若名称、时长或大小不同，会先提示确认。

Offset 微调按钮支持左右拖动和滚轮：每像素/格 1ms，Shift 为 10ms，操作时暂停。时间缩放以视图中的播放头为中心；播放头不在视图时以视图中心缩放。

新建或打开其他谱面会提示未导出的修改；关闭或刷新页面时使用浏览器离开提醒。导出通过浏览器下载，网页无法确认用户是否取消下载，导出后请确认文件已保留。没有自动保存或崩溃恢复。

## 谱面格式

```json
{
  "version": 1,
  "meta": {
    "title": "Example",
    "seed": 1,
    "bpm": 120,
    "offsetSeconds": 0.125,
    "ppq": 480,
    "timeSignature": { "numerator": 4, "denominator": 4 },
    "music": { "name": "music.flac", "duration": 60, "size": 123456 }
  },
  "notes": [
    { "id": "stable-note-id", "tick": 480, "height": 0.5 }
  ]
}
```

`music` 可以为 `null`。音频时间 = offsetSeconds + tick × 60 / (bpm × 480)。高度为 0..1，顶部为 0。每个音符有唯一 ID。BPM/offset 修改不改变 tick。同刻音符和超出音乐范围的音符会警告但保留；版本、非法数据、重复 ID 等错误则拒绝导入，并保留当前项目。兼容旧规划示例中的 `beatsPerBar`（按分母 4 导入），导出统一使用 `timeSignature`。渲染器应遵循相同时间公式，不从这里读取怪物或动作参数。

## 初版边界

已实现：音乐与时间基础、二维画布、基础快捷键编辑、JSON 保存重载、循环试听与错误提示。未实现自动 BPM/节拍分析、变速 BPM、音符复制/批量移动、撤销重做、自动保存、渲染和视频输出。J/K/L、N、Ctrl+B、Ctrl+Q、X/C/Z 等后续功能尚未绑定。

源代码：`core.ts` 负责格式与时间计算；`audio.ts` 负责 Web Audio 时钟、解码和波形；`Editor.tsx` 负责画布；`App.tsx` 负责项目操作与界面。

怪物外观由渲染器分配，制谱器不指定怪物类型。meta.seed 为 0 到 4294967295 的整数；旧谱面缺失时使用 1。制谱器导入与导出保留该字段，渲染器重新随机后应保存谱面。

相关文档：[渲染器说明](../renderer/README.md)、[当前实现与后续计划](../../docs/MVP_IMPLEMENTATION_PLAN.md)。

## 音符音效与逐拍标尺

试听时每个音符按命中时间播放内置 `src/assets/tap.wav`（用户提供的 PhiEditer tap.wav 副本）。默认开启，可用“音符音效”按钮静音；音乐音量与音效分开。暂停、跳转时取消已排程的音效，循环区间内的音符每轮重播。音效通过 Web Audio 时钟提前调度，不通过画面帧触发。音乐范围外的音符不发声。

顶部标尺不再分小节，逐拍连续编号 1、2、3……，每拍内按 subdivision 细分；低缩放时会稀疏显示编号以避免重叠，吸附精度不变。拍号分母仍决定每拍时值，导出格式不变。

启动固定使用 5173 且禁止自动切换端口。再次双击 start.cmd 会打开已有制谱器页面，不创建另一个服务。关闭网页标签不会停止服务器；在启动终端按 Ctrl+C 停止。5174 动画导入器、5175 渲染器属于其他工具。

## 框选删除与快捷缩放

暂停时在音符区域按住 Ctrl，按下左键拖出矩形，松开左键完成框选。音符中心落入矩形即被选中，支持任意方向拖动；新框选替换旧选择。选中音符高亮并显示数量，按 Delete 批量删除。Esc 或右键取消框选，不删除音符；取消后仍保留原先的悬停右键/Delete 单音符删除。框选仅用于删除，不支持复制或移动。播放、新建、载入谱面时清除选择。

鼠标位于制谱画布内时，Ctrl＋滚轮向上放大时间尺度，向下缩小，以鼠标所在时间为缩放中心（视图边界会限制位置），范围与缩放滑块一致。仅改变视图，不移动音符或播放头。普通滚轮仍用于时间定位；画布外保留浏览器原有 Ctrl＋滚轮行为。

制谱器仍读取独立谱面 JSON。渲染器的 renderer.json 是包含音乐、图片和两种模式设置的完整工程，不能直接作为谱面导入；需要在渲染器中用“保存谱面”导出后再编辑。
