# 素材统一调色 v001

动作文件：`PV_Color_v001.atn`。已通过 Photoshop 界面录制并批量验证。

源文件保留在 `src/ProcessedStopMotionMovie/`；本次校正结果位于 `src/ColorCorrectedStopMotionMovie_v001/`，包含 Idle 4 张和 Upperhit 5 张。

## 固定参数

使用「图像 → 调整 → 色阶」，RGB 复合通道不调整，分别设置：

| 通道 | 输入黑场 | Gamma | 输入白场 | 输出黑/白场 |
| --- | ---: | ---: | ---: | --- |
| 红 | 24 | 1.00 | 195 | 0 / 255 |
| 绿 | 23 | 1.00 | 194 | 0 / 255 |
| 蓝 | 22 | 1.00 | 191 | 0 / 255 |

目标是提亮灰白纸面、压深黑色轮廓，保留纸面与手绘纹理；不保证所有白色像素变成纯白。没有使用逐张自动色阶，没有缩放、裁切或修改透明度。

## 后续复用

1. 将未调色的透明 PNG 复制到新的输出目录，保留组别子目录。不要把已校正文件再次作为输入，否则会重复加深调色。
2. Photoshop 动作面板菜单选择「载入动作」，载入 `PV_Color_v001.atn`（当前 Photoshop 已有此组，无需重复载入）。
3. 「文件 → 自动 → 批处理」，组选择 `PV_Color_v001`，动作选择 `RGB_Levels_24-195_23-194_22-191`。
4. 源选择新建的副本目录，勾选「包含所有子文件夹」；目标选择「存储并关闭」。这会写回所选副本目录，因此不要选择原始素材目录。
5. 动作只有色阶一步，不包含固定文件路径、打开、保存、裁切或关闭步骤；保持「覆盖动作中的打开/存储为命令」不勾选。
