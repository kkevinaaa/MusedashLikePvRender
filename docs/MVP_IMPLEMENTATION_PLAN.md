# MuseDash Like PV：当前实现与后续计划

本文记录当前功能范围及已确认的设计规则。具体操作见[制谱器](../software/chart-editor/README.md)、[渲染器](../software/renderer/README.md)和[动画导入器](../software/animation-importer/README.md)说明。后续计划中的功能尚未实现。

## 项目分工

制谱器和渲染器是两个独立的本地网页 App，通过 JSON 谱面衔接。制谱器负责音乐校准与音符编辑；渲染器加载音乐、谱面和 PNG，播放类 Muse Dash 的节奏 PV。动画导入器既可独立使用，也已嵌入渲染器的“素材”窗口。

音符高度由人工编排，用来表达旋律走势。怪物按该高度水平飞行，人物只上下移动。当前成片通过全屏播放配合外部录屏软件获得。

## 已实现功能

| 模块 | 当前范围 |
|---|---|
| 制谱器 | 音乐导入与波形、固定 BPM 与拍号、offset 校准、二维音符放置和删除、时间与高度吸附、横向滚动缩放、循环试听、JSON 导入导出 |
| 渲染器 | 全部击打与全部 Miss、seed 怪物分配、人物移动和动作选择、待机浮动、片段播放、暂停与跳转、配置保存、倒计时与全屏录屏界面 |
| 动画导入器 | 六个素材槽位、PNG 数字排序及手动重排、整组缩放旋转裁剪、第一帧锚点、逐帧和播放预览、待机叠影、配置保存与素材重关联 |

制谱器用 Q 放置音符，右键或 Delete 删除悬停音符。时间细分为每拍 2/3/4/6/8 等分；“每拍”按拍号分母定义。T 控制时间吸附，V 联动控制高度辅助线显示和吸附。网格变化只影响后续放置，不移动已有音符。初版没有选区、拖动、复制、撤销或重做，放错时删除后重放。

循环试听属于制谱器。渲染器播放指定片段并收尾，不循环。

## 谱面与保存格式

时间使用整数 tick，固定 480 PPQ。BPM 以四分音符计；高度为 0 到 1，0 对应可打击区域顶部，1 对应底部。

```text
音频时间（秒） = offsetSeconds + tick × 60 / (BPM × 480)
```

正 offset 表示第一小节第一拍晚于音乐开头。修改 BPM 或 offset 不改写音符 tick。

```json
{
  "version": 1,
  "meta": {
    "title": "Example",
    "bpm": 160,
    "offsetSeconds": 0.125,
    "ppq": 480,
    "timeSignature": { "numerator": 4, "denominator": 4 },
    "seed": 1,
    "music": null
  },
  "notes": [
    { "id": "note-1", "tick": 1920, "height": 0.32 }
  ]
}
```

`music` 可为 null，也可保存音乐文件的 `name`、`duration`（秒）与 `size`（字节）。导入兼容旧的 `beatsPerBar` 字段，按分母 4 转换；导出统一使用 `timeSignature`。

seed 保存于谱面 `meta.seed`，范围为 0 到 4294967295 的整数，缺失时默认 1。制谱器保留该字段；渲染器“重新随机”修改 seed 后，需要另存谱面。怪物外观由 seed 和稳定音符 ID 分配，复现还要求相同的素材顺序和启用列表。音符不保存怪物类型或动作参数。

渲染配置使用独立 JSON，包含 `version: 1`、`settings` 和 `assets`。它保存画面、动画参数、怪物启用列表及已应用的素材配置。素材窗口也可单独导出配置，格式为 `version: 1`、`fps` 和 `slots`；两种配置入口对应不同格式。

JSON 不包含音乐和 PNG。重新打开后需关联原资源；素材按原文件名重新关联可保留矫正。原始图片不会被改写。导出依赖浏览器下载，没有自动保存或崩溃恢复。

## 渲染规则

逻辑画布固定为 1920×1080。人物和命中特效默认按 8fps 换帧，帧率可在素材窗口调整；怪物飞行与人物上下位移按浏览器刷新率绘制。播放状态依据 Web Audio 时钟计算，暂停和跳转后按当前时间重建画面。

| 行为 | 全部击打 | 全部 Miss |
|---|---|---|
| 怪物 | 从右侧进入，音符时刻到达打击线并消失 | 穿过打击线，完整离开左侧后消失 |
| 人物 | 直接追踪谱面高度，按移动起点与目标的高度差选择上打、下劈或平砍 | 在高度 0.5 附近待机浮动 |
| 特效 | 音符时刻出现 | 不播放 |
| 同刻多音符 | 检测到冲突时阻止播放 | 支持 |

同刻检测覆盖当前片段结束前的事件。音乐范围外的音符在制谱器中警告并保留，渲染器会阻止播放，需先修正。

人物追位使用固定时长的 `easeOutCubic`。新追位截断旧移动，并从当前高度重新开始；新攻击截断旧攻击，从第一帧开始，均不加速。密集音符可能在人物尚未到位时命中。空闲时叠加可调幅度和周期的正弦浮动。

攻击开始时间等于音符时间加攻击偏移，负值提前、正值延后。该参数只影响攻击动画，不改变怪物和特效的时间。人物站位直接使用谱面高度，不按武器命中点反推，也不逐动作标定命中帧。统一 X/Y 偏移用于特效定位和调试参考，单位为逻辑像素；特效基于人物横坐标和音符目标高度定位。

“从头播放”和“录屏模式”会预演入场。预演时长取倒计时、怪物飞行时间、移动提前量与攻击提前时间中的最大值，音乐从片段起点开始。普通播放或继续不额外预演。片段末尾至少保留设定收尾时长，必要时延长至最后动作、特效或漏过怪物结束，收尾期间没有额外音频。

## 素材与工程

槽位顺序为待机、上打、下劈、平砍、命中特效、怪物。动画组共用一套变换和第一帧锚点，怪物逐张设置。裁剪与锚点使用原始 PNG 坐标，裁剪不改变站位。

项目预设读取根目录 `src/EquidistantWhiteEdgeStopMotionMovie/`，对应子目录为 `Idle`、`Upper`、`Lower`、`Stright`、`Hitfx` 和 `Monsters`。四组人物默认共用待机首帧主体中心作为锚点，仅供开始调校。怪物数量由导入素材决定，不写死为六张。根目录 `src/` 已被 Git 忽略，克隆仓库后需自行准备素材和音乐，也可在窗口中手动导入 PNG。

制谱器使用 React、TypeScript、Vite、Canvas 2D 和 Web Audio，自行生成波形。渲染器与动画导入器使用 JavaScript、Vite 和 Canvas 2D；渲染器复用制谱格式解析及动画导入器源码。当前没有使用 WaveSurfer.js 或自动节拍分析库。

现有单元测试和浏览器脚本覆盖谱面格式、时间换算、素材变换、seed、两种播放模式及保存重载等行为。运行方法见各模块 README；外部录屏的实际音画质量仍需单独检查。

## 后续工作

以下项目尚未实现，按实际需要安排，不代表已确定的开发顺序：

- 制谱编辑：撤销重做、选择与复制、批量编辑、自定义高度辅助线、自动保存。
- 音乐辅助：BPM 与节拍候选、指定第一小节第一拍、变速 BPM 与变拍号、MIDI 等格式导入。
- 播放扩展：单音符指定怪物或动作、同刻击打规则、背景与镜头、额外视觉特效。
- 项目打包：包含音乐、谱面和图片的 ZIP 项目包、版本迁移。
- 视频输出：浏览器录制、WebM/MP4 导出、PNG 帧序列、固定帧率离线渲染及输出参数。

自动旋律音高识别、移动端适配和云端协作不在当前初版范围内。
