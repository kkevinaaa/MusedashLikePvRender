# MuseDash Like PV 网页工具：初版实现范围与后续计划

## 1. 项目目标

制作一个本地运行的网页工具，用于导入音乐、谱面和手绘素材，编辑“时间—高度”二维谱面，并播放一小段类 Muse Dash 的节奏 PV。

怪物从画面右侧飞入，在音符时间到达左侧固定打击线。音符高度由制谱者人工放置，不要求程序从音乐中严格识别音高。人物只能上下移动，根据目标怪物相对当前位置的方向播放上打、下劈或平砍动作；没有攻击时播放待机动作。六种怪物只随机外观，不随机谱面高度。

初版优先保证编辑、试听和播放稳定，成片先通过全屏播放后录屏获得。自动视频渲染、抽帧和转码放到后续阶段。

## 2. 已确认的设计决定

### 2.1 素材风格与帧率

- 对角色、攻击特效和怪物素材做裁切、透视校正、亮度与纸张颜色统一、轻度降噪锐化和去背景。
- 保留类似 `src/Ref/CropRef.png` 的不规则白色包边，白边以外透明。
- 所有角色动作统一画布尺寸、缩放、人物站位锚点和命中锚点，减少逐帧抖动。
- 人物逐帧动画和命中特效按约 8fps 播放。
- 怪物飞行与人物上下位移仍按浏览器刷新率平滑插值，不将整个画面限制为 8fps。

### 2.2 谱面坐标

- 制谱画布采用二维坐标：横轴是时间，纵轴是怪物命中高度。
- 横轴使用整数 tick 保存，不直接保存浮点秒数；初版建议采用 480 PPQ。
- 纵轴保存为 `0..1` 的归一化高度，`0` 表示画面顶部，`1` 表示画面底部，避免谱面与具体分辨率绑定。
- 编辑器纵向区域直接对应播放器中的可打击区域，初版不做纵向滚动；时间轴横向滚动和缩放。
- 音符的纵向位置由制谱者人工放置。六种怪物类型在播放或导出时随机分配。

### 2.3 辅助线与吸附

- 小节线和节拍线始终可见。
- 提供每拍 2、3、4、5、8 等分的网格切换，用作当前放置和拖动时的时间吸附精度。
- 增加可选的横向高度辅助线，用来让多个音符保持相同或规律的高度。
- “显示横向辅助线”和“吸附横向辅助线”分别开关，避免只想参考线条时被强制吸附。
- 初版可先提供等距横向辅助线数量设置；自定义添加、拖动和命名辅助线列入后续增强。

### 2.4 BPM 与 offset

- 支持手动输入 BPM、offset、拍号和曲名。
- 自动分析只给出 BPM 和节拍位置候选，不直接覆盖用户设置。
- 用户可以点击某条候选节拍线，将其指定为第 1 小节第 1 拍。
- offset 提供数值输入和滚轮/拖拽调节控件，并在调整时实时试听和移动网格。
- 滚轮需要支持细调与粗调，例如普通滚轮按 1ms 步进、按住 `Shift` 后按 10ms 步进；具体步长可在实现时根据手感调整。
- 调整 offset 时只改变音乐时间与谱面 tick 的映射，不重写已有音符的 tick。
- 初版仅支持固定 BPM 和固定拍号，不支持歌曲中途变速。

### 2.5 随机怪物

- 谱面音符保存时间与人工放置的高度，不直接保存随机怪物结果。
- 项目保存一个随机 seed。相同谱面和 seed 每次播放都得到相同的怪物种类序列。
- 提供“重新随机”按钮：生成新 seed，而不是让每次播放自动变化。
- 可选支持锁定单个音符的怪物类型；未锁定音符继续按 seed 随机。此项可视初版进度决定是否加入。

### 2.6 人物移动与攻击选择

- 根据当前人物高度与下一个音符高度的差值选择动作：目标明显偏上时上打，明显偏下时下劈，高度差在阈值内时平砍。
- 人物在命中前进入移动阶段，通过 `easeOutCubic` 快速移动到目标站位。
- 人物站位不是简单等于音符高度，而应满足：`人物站位 + 当前动作命中点偏移 = 音符高度`。
- 每种攻击动作需要独立标定命中点偏移和命中帧。
- 空闲时循环播放待机；攻击结束后恢复待机或直接衔接下一次移动/攻击。
- 连续音符过密时，初版允许压缩移动时间并从当前状态切换到下一动作，之后再增加更严格的动作衔接规则。

## 3. 初版功能范围

### 3.1 项目与资源导入

- 创建新项目并填写名称、BPM、offset、拍号和随机 seed。
- 导入本地音乐文件并显示时长和波形。
- 导入预处理后的角色动作、命中特效和六种怪物 PNG。
- 导入、导出自定义 JSON 谱面。
- 校验缺失资源、无效 BPM、音符越界和谱面版本。

初版可以分别选择音乐、谱面和素材目录。后续再增加单文件项目包，例如包含 `chart.json`、音乐和图片的 ZIP。

### 3.2 制谱器

- 横向时间卷轴和缩放。
- 音乐波形、播放头、小节线、节拍线和 subdivision 网格。
- 可切换每拍 2、3、4、5、8 等分吸附。
- 二维画布中单击放置音符，拖动修改时间和高度。
- 选中、删除、复制音符。
- 可选横向高度辅助线，以及独立的显示/吸附开关。
- 播放、暂停、从光标处播放和点击时间轴跳转。
- BPM、offset 数值输入；offset 滚轮/拖拽微调并实时试听（调节滚轮时自动暂停，按下播放按钮后开始试听）。
- 显示自动 BPM/节拍候选，并允许指定第 1 小节第 1 拍。
- 重新随机怪物预览。
- 保存与载入谱面 JSON。

### 3.3 播放器

- 读取音乐、谱面和素材配置。
- 按谱面时间提前生成怪物，并从右侧飞向固定打击线。
- 怪物的纵向目标使用音符的人工高度。
- 在命中前移动人物，按移动方向选择攻击动作。
- 命中时播放 8fps 攻击序列和命中特效，随后移除怪物。
- 无攻击时循环待机动作。
- 使用音频时钟计算所有状态，支持暂停、继续和跳转后正确恢复画面。
- 提供全屏、无编辑 UI 的录屏模式，以及播放前倒计时。
- 提供调试叠层开关，可显示打击线、人物锚点、动作命中点、音符时间和当前 seed。

### 3.4 初版暂不实现

- 浏览器内直接导出 MP4。
- 自动抽帧序列。
- 变速 BPM、变拍号和完整 tempo map。
- 从完整混音自动识别旋律音高。
- MIDI、osu! 等第三方谱面格式导入。
- 多人协作和云端存储。
- 复杂背景、镜头动画和粒子编辑器。
- 移动端制谱适配。

## 4. 建议的数据格式

```json
{
  "version": 1,
  "meta": {
    "title": "Example",
    "bpm": 160,
    "offsetSeconds": 0.125,
    "beatsPerBar": 4,
    "ppq": 480,
    "seed": 123456
  },
  "playback": {
    "travelBeats": 4,
    "spriteFps": 8,
    "hitLineX": 0.24,
    "moveLeadBeats": 0.5
  },
  "notes": [
    {
      "id": "note-1",
      "tick": 1920,
      "height": 0.32,
      "monsterType": null
    }
  ]
}
```

`monsterType: null` 表示由 seed 随机分配；以后若需要手动锁定某只怪物，可写入具体类型。音乐和图片不以内嵌 Base64 形式写进 JSON，避免谱面文件过大。

## 5. 建议的技术结构

- TypeScript + React + Vite：页面和状态管理。
- Canvas 2D：二维谱面编辑层和 PV 播放画面。当前对象数量不多，初版没有使用 WebGL/PixiJS 的必要。
- Web Audio API：音乐解码、播放和主时钟。
- WaveSurfer.js：波形显示；音乐网格和音符层仍由项目自己的 Canvas 绘制。
- `web-audio-beat-detector` 或同类浏览器库：BPM 和初始 offset 候选。
- 编辑器和播放器共用同一套时间换算、随机分配和动画状态计算模块，避免试听结果与最终播放不同。

## 8. 开工前仍需确定的问题

1. 初版目标画幅与分辨率，例如 1920×1080、2560×1440 或竖屏比例。
2. 怪物从出生到打击线的移动时间，建议用拍数表示，例如提前 4 拍出生。
3. 人物移动提前量，以及三种攻击各自在哪一帧命中。
4. 高度接近时选择平砍的阈值。
5. 同一时间是否允许多个音符；如果允许，人物如何同时处理不同高度。
6. 过密音符时允许动作截断，还是由编辑器提示并禁止。
7. 横向辅助线初版只做等距线，还是第一版就需要自由添加和拖动。
8. 素材统一输出尺寸，以及白边宽度采用固定像素还是按人物尺寸比例计算。
