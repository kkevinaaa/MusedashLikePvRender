# 调色 v002：轻微降低饱和度

在 v001 动作的色阶步骤后追加 Photoshop「色相/饱和度」：全图（Master），色相 0、饱和度 -10、明度 0，不勾选着色。

动作文件：`PV_Color_v002_SatMinus10.atn`。动作组：`PV_Color_v002_SatMinus10`；组内动作仍名为 `RGB_Levels_24-195_23-194_22-191`，包含色阶、色相/饱和度两个步骤。

原色阶参数保持不变：红通道输入 24 / 1.00 / 195，绿通道 23 / 1.00 / 194，蓝通道 22 / 1.00 / 191；输出均为 0–255。

本次只处理 Idle 的 4 帧，输出位于 `src/ColorCorrectedStopMotionMovie_v002/Idle/`。逐帧验证为 1920×1080，透明通道与原始抠图逐像素一致。原始素材和 v001 均保留。

复用时，先复制 `src/ProcessedStopMotionMovie` 中未调色的素材到新的输出目录，再对副本执行本动作。不要对 v001 或已处理的 v002 再执行整个动作，否则会重复叠加色阶。若只想在 v001 上补降饱和，只执行第二个色相/饱和度步骤。
